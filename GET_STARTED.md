## Get started

- Copy `.env.example` to `.env`
- Run `npm install`
- Run `npm run all`

alternatively: for cleaner logs
- Run `npm run api` in one terminal
- Run `npm run dev` in a second terminal and open the URL

## MySQL

- install mysql
- `systemctl start mysql` (might need sudo)
- install client: DataGrip by JetBrains or XAMPP
- Create the database, then run `database/schema.sql`
